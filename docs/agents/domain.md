# Domain Docs

Repository menggunakan layout single-context.

Sebelum mengeksplorasi atau mengubah kode:

- Baca `CONTEXT.md`.
- Baca ADR yang relevan di `docs/adr/` jika tersedia.
- Gunakan istilah canonical dari glossary dan hindari sinonim yang ditandai `_Avoid_`.
- Jika usulan bertentangan dengan ADR, nyatakan konflik tersebut secara eksplisit.
- Ketiadaan dokumen domain tertentu bukan blocker; dokumen dibuat secara bertahap melalui domain modeling.
