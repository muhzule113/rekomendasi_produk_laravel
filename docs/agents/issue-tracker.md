# Issue tracker: GitHub

Issues dan PRD repository ini disimpan sebagai GitHub Issues pada `muhzule113/rekomendasi_produk_laravel`.

Gunakan `gh` CLI untuk operasi issue. Jika CLI tidak tersedia, gunakan konektor GitHub terautentikasi dengan operasi yang setara.

## Conventions

- Membuat issue: buat GitHub Issue dengan judul, body, dan label yang diminta.
- Membaca issue: ambil body, komentar, dan label.
- Memperbarui issue: tambahkan komentar atau ubah label tanpa menghilangkan metadata lain.
- Menutup issue: beri komentar penutup bila konteks penyelesaian perlu dicatat.
- Infer repository dari remote `origin`.
- Pull request bukan permukaan triage.

## When a skill says "publish to the issue tracker"

Buat GitHub Issue pada repository ini.

## When a skill says "fetch the relevant ticket"

Ambil issue beserta komentar dan labelnya.
